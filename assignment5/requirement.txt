Web Hacking Assignment
Due Wednesday by 11:59pm Points 100 Submitting a file upload File Types pdf
In this assignment students will explore basic web hacking techniques and tools. From a cloud security perspective, it is important to be familiar with web hacking threats since cloud solutions often are exposed via attack surfaces that include web management interfaces and APIs. These often contain web application vulnerabilities that attackers will actively search for, target and exploit to gain unauthorized access. Understanding the offensive aspects of web application security is valuable with regards to making cloud solutions more secure and managing associated risks to an acceptable level.

The student should submit a brief report documenting all work performed, including any analysis and use of tools carried out to complete the exercises in this assignment. Use screenshots where appropriate.

Web application proxy
Installation and configuration
[*] Ensure you have a working web proxy to intercept requests and modify them.

Use a proxy that comes pre-installed in Kali or install an additional a web proxy that fits your needs.
Hint. For simpler web application analysis tasks that do not require heavy automation and complex payloads, the browser built-in web developer tools can be used.

Hint. Certain web application proxies may have useful required features that are restricted unless you buy the pro version eg rate limitations.

 

[*] Configure the web proxy to listen on an appropriate port.

Use a port that does not conflict with existing listening ports.
Hint. The Linux commands ss and netstat are useful for displaying ports with associated listening services in the Kali VM.

Hint. In order to proxy TLS/SSL traffic you first need to import the web proxy CA certificate into the browser.

 

 

[*] Add a proxy manager to the browser.

Install a proxy manager so that it is easier to toggle the proxy on and off when required or switch between multiple proxies.
Add your web proxy to the proxy manager and configure the options accordingly.
Test that the web proxy is working as expected together with the proxy manager.
Hint. Use the browser add-on/extension search functionality to find a suitable proxy manager.

Hint. More and advanced web proxy options is not necessarily better depending on what you will be doing with your proxy.

 

[*] Document the web proxy manager and proxy setup and configuration with screen shots. What were the challenges to get the proxy up and running? Provide a brief analysis that discusses which proxy was chosen and why, including pros and cons of the web proxy used.
